# Shrine Process PWA — Change Request 04

Applies on top of v1, CR01, CR02 and CR03. Where they disagree, this document wins.
Requirements continue as `CR-151` onward.

Scope: Schedule tab only. Nothing in this change appears on, or is reachable from, the
`/book` route or the Schedule Yourself tab.

---

## 1. REMOVE PERSON

**CR-151.** New action on an assigned slot card: **Remove person**. It sets the slot's
`personId` to null, clears `confirmedAt`, `kitAckAt` and `doneAt`, and clears the slot's
note. The slot returns to TBD and immediately shows as open on Schedule Yourself.

**CR-152.** Coordinator only. Available exclusively in the Schedule tab's expanded slot
panel. Never exposed on `/book`.

**CR-153.** No confirmation dialog. Instead, the snackbar reads
**"Removed — 12–14 Sep is open"** with an **Undo** action, held for 6 seconds instead of
the usual 2.1. Undo restores the person, all three acknowledgement timestamps and the
note exactly as they were.

**CR-154.** Hide Remove person on any slot where `doneAt` is set. A completed slot is
history; removing it would silently erase that person's last-done date. To correct a
wrongly completed slot, untick the lamp first, then Remove becomes available.

**CR-155.** Backend: add `POST { action: "removePerson", slot }`. Same write rules as
every other coordinator mutation — optimistic, queued, sequenced, never rolled back
(CR-14, CR-100 to CR-106).

**CR-156.** No email notification on a coordinator removal. The self-booking removal
email from CR-132 is unchanged and applies only to `/book`.

## 2. SLOT NOTES

**CR-157.** Add `note: string | null` and `noteUpdatedAt: string | null` to `Slot`, and
matching columns in the sheet. Plain text, 280 characters max, no formatting.

**CR-158.** The note belongs to the slot's current assignment. It is cleared by
**Replace person** and by **Remove person** (restored by Undo, per CR-153).

**CR-159.** Visible without expanding. When a note exists, the collapsed slot card shows
it as one extra line beneath the dates: a 14px note glyph, then the note text in 13px
`--text-2`, truncated to a single line with an ellipsis. Cards without a note are
unchanged in height.

**CR-160.** Panel row label is **Add note** when the slot has no note and **Edit note**
when it does.

**CR-161.** Tapping it opens a bottom sheet — not the full-screen picker:

| Region | Contents |
|---|---|
| Header | "Note", and beneath it the person's name and slot dates in `--text-2` |
| Body | Multi-line text field, auto-focused, pre-filled with the existing note. Placeholder: "Status, follow-ups, anything to remember" |
| Footer | **Clear** (only when a note exists), **Cancel**, **Save** |

The sheet sits above the keyboard and the text field stays visible while typing,
per the CR-21 to CR-23 rules.

**CR-162.** Save writes the trimmed text and `noteUpdatedAt`; saving an empty field is
the same as Clear. Snackbars: "Note saved" · "Note cleared".

**CR-163.** Backend: add `POST { action: "setNote", slot, note }`, under the same write
rules as CR-155.

## 5. AVAILABILITY REQUEST TEMPLATE

**CR-164.** Add a row to the `Templates` tab:

| Column | Value |
|---|---|
| `id` | `availability_request` |
| `label` | Availability request |
| `scope` | `empty_slot` — a new scope value; the panel in Section 4 reads it |
| `channel` | `message` — copies as plain text |
| `subject_en` | empty |
| `body_en` | see below |

```
Namaskaram Swami/Maa 🙏

Would you be able to do Shrine process from {{slot_dates}}?
```

**CR-165.** `{{slot_dates}}` resolves to the empty slot's dates in the template date
style, e.g. "Sep 12 - 14", "Sep 30 - Oct 2".

**CR-166.** The greeting is literal text, not `{{title}}` — an empty slot has no person
to resolve a title from.

**CR-167.** Snackbar on copy: "Availability request copied".

## 6. TESTS

1. Remove a person from a future slot: card turns TBD, acknowledgements and note gone,
   slot shows as open on Schedule Yourself after a refresh there.
2. Tap Undo within 6 seconds: person, all three ticks and the note return exactly.
3. Remove person does not appear on a slot whose lamp is ticked; untick it and it does.
4. Remove with the network off: card stays TBD, syncs on reconnect, never reverts.
5. Add a note: one-line preview appears under the dates on the collapsed card.
6. A note longer than one line truncates with an ellipsis; full text shows in the sheet.
7. Edit, then Clear: preview disappears, card returns to normal height.
8. Replace person clears the note.
9. Empty slot panel shows exactly Add person and Availability request.
10. Availability request copies with the correct dates, including a slot that crosses a
    month boundary.
11. None of the new actions are reachable anywhere on `/book`.
